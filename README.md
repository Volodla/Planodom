# Planodom — первая версия

Главная и пример записи блога, сохранённые шрифты, цвета и логотип исходного сайта.

## Просмотр

Откройте `index.html` или запустите в каталоге проекта:

```sh
python3 -m http.server 8080
```

## Развёртывание

Это статическая версия для проверки дизайна, ещё не WordPress. Для публикации загрузите `index.html` и каталог `assets` на статический хостинг. Отдельно создаём тему WordPress после проверки первой версии.

Формы работают в демонстрационном режиме, заявки не отправляются. Видеообзоры требуют ссылок на видео. Кнопке MAX нужна ссылка компании. Перед рекламным запуском необходимо подключить обработку заявок и аналитику.

Файл `image-sources.json` содержит адреса изображений исходного сайта. Изображения сохранены локально: опубликованная версия не зависит от загрузки картинок с Tilda.
