# WordPress — Planodom

Тема 0.1.0 на основе согласованного макета. Главная создаётся при активации и редактируется как страница WordPress (HTML). Блог использует стандартные записи WordPress. Статьи из Tilda ещё не импортированы.

На new.planodom.ru тема принудительно отдаёт noindex/nofollow и X-Robots-Tag. Дополнительно загрузите robots.txt в корень сайта. Это запрет индексации, а не ограничение доступа.

Формы сохраняют заявки как приватные записи «Заявки сайта» и отправляют уведомление на admin_email WordPress. Настройте рабочий адрес и SMTP перед использованием. CRM не подключена. MAX требует реальной ссылки компании.

Сборка: python wordpress/build-theme.py. Архив включает только используемые изображения из assets основного репозитория. Установите архив через Внешний вид → Темы → Добавить → Загрузить тему.

Проверено: синтаксис JavaScript и наличие 82 файлов изображений. PHP CLI недоступен в среде сборки; перед запуском необходима проверка PHP и браузерная проверка на хостинге.
