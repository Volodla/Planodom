# WordPress — Planodom 0.2.1

Рабочая тема на основе согласованного макета. Главная редактируется как страница WordPress. Разделы сайта — стандартные страницы; проекты и построенные дома — отдельные типы записей с редактором, галереей, обложкой и ревизиями. Блог — стандартные записи и категории WordPress.

## Сборка и обновление

`python3 wordpress/build-theme.py`

Для первой сборки из чистого Git checkout нужен Pillow (`python3 -m pip install Pillow`) и доступ к исходным изображениям Tilda. 164 изображения галерей загружаются по зафиксированному `source-assets.json`, оптимизируются без обрезки и входят в ZIP. Повторная сборка использует уже загруженные файлы. Архив создаётся через временный файл и проходит CRC-проверку перед заменой итогового ZIP.

Архив `wordpress/planodom-wordpress-theme.zip` содержит тему, исходный и обновлённый HTML главной, снимок подготовленного контента и локальные изображения. Установка или обновление: Внешний вид → Темы → Добавить → Загрузить тему. Затем Инструменты → Контент Planodom → Импортировать подготовленный контент. Повторный импорт не перезаписывает существующие материалы. Первая главная заменяется только при точном совпадении с исходной; резервная копия хранится в `pd_home_backup_v1`. Стандартные Sample Page и Hello world перемещаются в корзину с возможностью восстановления.

## Контент

- 21 проект: описания и комплектации из публичного сайта Planodom, 164 локальных изображения галерей (изображения оптимизированы до 2000 px без обрезки).
- 15 страниц построенных домов: название и фотографии из исходного макета.
- 12 дополнительных страниц: каталог, построенные дома, комплектация, технология, компания, ипотека, бизнес, просмотр, видео, контакты, политика, спасибо за заявку.
- 3 редакционных материала для блога: выбор планировки, комплектация под ключ, подготовка к консультации. Опубликованных статей в sitemap старого сайта не обнаружено; это новые материалы, а не архив публикаций Tilda.
- `/politconf/` и `/sps/` сохранены; старые технические посадочные адреса перенаправляются на актуальные разделы.
- Политика перенесена из источника; ошибочное имя «Перепланировка» заменено на ИП из реквизитов действующего сайта. Юридический текст и реквизиты следует подтвердить у владельца перед запуском на основном домене.
- Числовые обещания по ипотеке заменены на условия конкретной банковской программы; добавлена ссылка на действующие условия Банка ДОМ.РФ.

`migrate-source.py` — утилита подготовки чернового снимка из HTML-источников, требующая lxml и Pillow. Она не нужна для стандартной сборки и не перезаписывает проверенные `content.json` и `home-v2.html`. Исходные URL проектов сохранены в метаданных `_pd_source`.

## Шаблоны и проверки

Статья: обложка, категория, дата, время чтения, автоматическое оглавление, основные HTML/WordPress-блоки, проекты по теме и другие статьи. Отдельные виды для страниц, проектов, архива/поиска и 404. Метаописания, Open Graph и BlogPosting. Галереи в отдельном административном блоке. Пагинация архивов.

На `new.planodom.ru` сохраняются WordPress blog_public=0, noindex/nofollow, X-Robots-Tag и запрет robots.txt. Индексация не ограничивает доступ посетителей.

Формы сохраняют приватные записи «Заявки сайта» и отправляют уведомление на admin_email. Приём заявки и статус отправки почтовому сервису — разные проверки; SMTP/доставка и CRM требуют настройки. Для администратора URL `/?pd_test=1` включает тестовый режим форм: запись сохраняется, письмо не отправляется. Тестовые записи можно переместить в корзину после проверки. MAX отключён до предоставления реальной ссылки компании.

PHP проверяется парсером PHP 8.1, JavaScript — `node --check`. Реальное выполнение PHP и функции WordPress проверяются на тестовом хостинге после обновления.
